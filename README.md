# K-Nearest Neighbors (KNN) From Scratch 

This repository contains an implementation of **K-Nearest Neighbors (KNN) from scratch using NumPy**.  
The project demonstrates how the KNN classification algorithm works internally without using machine learning libraries for the core logic.


##  Features Implemented

- Custom KNN Classifier
- Euclidean Distance Calculation
- Nearest Neighbor Search
- Majority Voting using `Counter`
- Model Training & Prediction
- Accuracy Evaluation
- Classification Report
- Optimal K Value Search
- Comparison with Scikit-learn KNN



##  Topics Covered

- K-Nearest Neighbors Algorithm
- Distance Metrics
- Classification Problems
- Feature-Based Prediction
- Majority Voting Mechanism
- Hyperparameter Tuning (`K` Value)
- Model Evaluation
- Data Visualization using Pairplots



##  Technologies Used

- Python
- NumPy
- Pandas
- Seaborn
- Scikit-learn
- Jupyter Notebook



##  Dataset Used

- Iris Dataset

The project uses the famous Iris flower dataset for multi-class classification.



##  Goal of This Repository

The main goal of this repository is to deeply understand how the KNN algorithm works internally by implementing it completely from scratch.

This project focuses on:
- Distance-based learning
- Neighbor searching
- Classification logic
- Performance evaluation
- Understanding machine learning fundamentals
